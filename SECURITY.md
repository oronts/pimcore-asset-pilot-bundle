# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | yes       |

## Reporting a vulnerability

Please do not open a public issue for security problems. Email **office@oronts.com** with:

- a description of the issue and its impact,
- the affected version and environment (Pimcore and PHP versions),
- steps to reproduce, ideally with the smallest configuration that triggers it.

We will acknowledge the report, confirm the issue, and coordinate a fix and disclosure timeline with
you. Reports that touch the destructive paths (delete, move, quarantine, merge, revert) or the
permission gates are treated with priority.
